# 知衡教师备课助手

面向教师的 Windows 备课工作台，基于 DeepSeek Harness 原生插件。输入授课信息后，生成一份可编辑教学 PPT、教案、逐字稿、检测题和交付包；课后记录进入班级档案，供后续备课参考。

## 启动与使用

双击 `打开教师工作台.vbs`，或桌面的「教师工作台」快捷方式。本机地址：`http://127.0.0.1:3081/teacher/`。停止服务请运行 `停止教师工作台.cmd`。

1. 在「模型设置」确认文本模型；在「课件外观与服务」设置配图及可选生图服务。已有本机模型配置和密钥保留。
2. 在「知识库」导入自己的教材，查看章节、内容块和素材；识图描述按需开启。
3. 新建备课，填写主题、年级、学科、课时和班级，选择教材与已知学情，点击「创建课程并生成整套材料」。
4. 核对信息密度与材料，下载 PPTX、DOCX 或整套 ZIP。
5. 授课后保存课堂成果、困难和检测记录；下次为同一班级备课时参考已有记录，不自动重做上完的课。

详细步骤见 [Windows 使用说明](docs/Windows教师工作台_使用说明.md)。

## 当前架构

- `plugins/teacher-workbench/`：教师界面、DSH Agent、提示词、模型及素材服务。
- `backend/teacher_prep/`：教学设计校验、教材导入、知识检索、学情存储和材料导出。
- `config/`：模型、上下文、生成参数、配图与教材分块设置。
- `runtime/`、`harness-home/profiles/`：本机 DSH 运行时及插件加载配置。
- `harness-home/.credentials.yaml`：本机模型凭据，不随源码分发。
- `tools/`：安装检查、启动停止、导入及开发工具；`tests/`、`examples/` 为维护所需源码与示例。
- `data/`：运行时数据库、教材内容块、素材与任务记录。
- `inputs/`：待导入资料；`deliverables/`：生成材料及保留的源码部署包。

文本模型负责教学设计和逐页视觉方案，视觉模型描述教材图片；素材库原图可直接使用，可选生图服务补充插画，`python-pptx` 在本地装配为可编辑课件。具体模型与开关以本机设置为准。默认本地制作流程不依赖 Gamma。

## 检查与维护

```powershell
python tools/run_cli.py doctor
```

缺少 Python 依赖时运行 `python tools/setup.py --install`；开发检查入口为 `python tools/run_checks.py`。这些维护工具不代替真实教材与课堂内容核对。
