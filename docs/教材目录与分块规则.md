# 教材目录与内容块

上传 PDF 后按以下顺序处理：读取目录 → 核对正文标题 → 梳理章节和小节 → 形成内容块 → 提取并关联素材。界面显示当前阶段与读取页数，完成后可查看每章原文摘录、内容类型及内容块。

目录优先使用 PDF 书签，并用相邻正文标题校正页码。没有可用书签时，尝试读取前部的文字目录，再根据真实章节标题寻找 PDF 页序；不直接把印刷页码当成文件页序。无法可靠识别时保留全文范围，明确提示教师指定页码，不虚构章节。

章节梳理采用原文中的小节标题、例题/练习类型与原文摘录，不调用模型，也不把它们标成课程标准或教学目标。扫描 PDF 仍需先完成 OCR。数学竖式、分数和图示可能在文字层中表现为多行数字，原始 PDF 与图片保留供核对。

## 内容块的判定

| 类型 | 规则 |
| --- | --- |
| 概念与说明 | 同一章节、小节中相邻说明优先合并，目标约 650 字；短而独立的内容无需凑字数 |
| 例题与解答 | 题干、分析、解答、反思优先作为完整一组，普通上限可放宽到 2200 字 |
| 练习题组 | 保留题目条件、小问及题组关系，避免把数字和图示条件单独切走 |
| 整理复习、拓展阅读 | 按本身的内容边界独立组织 |
| 超长内容 | 普通内容块上限 1200 字；超过完整题组上限的内容沿句子/换行分片，记录同组ID与顺序，检索预算允许时一起取回 |

上述长度按提取出的文本字符计，包含必要换行，并非模型 token 数。章节边界优先于字数；实际教材中的短例题和短练习可以单独成块，不机械切成等长片段。

每块保存：稳定标识、章节和小节标识、教材路径、内容类型、原文、PDF 原册页码、原文块引用、关联图片标识。连续分片另有组标识、序号和总数。手动范围缺少连续内容的其他部分时会显示提示。检索不会再把这些完整块机械截成 1000 字；相邻补充限于同章节、同小节。

分块设置位于 `config/knowledge-chunking.json`，参考 `config/knowledge-chunking.example.json`：目标 650、合并小块参考值 180、普通上限 1200、完整题组上限 2200。修改后需要重新建立索引才能影响已有教材。原有模型温度和 API Key 设置不受影响。

## 一本教材，共享章节

原始 PDF、正文页、内容块和素材统一保存在一本教材下面。章节与自定义教学范围只记录起止页和来源，不再复制 PDF、全文或图片。相同图片可有多个出现页，但图片文件按内容共享。

旧资料迁移时保留知识库 ID、旧素材 ID、教师图注/描述及原有课程引用。旧 PNG 存在渲染编码差异时保留原字节作为共享素材，已有课程不会因此换图。迁移前备份完整知识库文件与数据库。备份属于恢复用途，不计入活动知识库的去重空间。

## 教师操作

1. 左下角「知识库」上传 PDF，等待目录与内容整理完成。
2. 点击「查看目录与分块」，查看章节内容、原文内容块和本章素材。
3. 新建备课，在「知识库依据」展开教材，点击「仅用本章」；跨章复习可多选或选择「仅用整册」。选章节时整册不会同时勾选。
4. 需要更小范围时，在「按指定页码添加教学范围」中填名称和页序，新范围会出现在教材下面。

管理范围引用可在章节面板展开「管理教学范围引用」。已被课程使用的引用保留，移除未使用引用不会删除整册和共享图片。

## 接口

- `GET /teacher/api/knowledge/index?knowledge=...`：章节、小节、来源摘录和分块设置。
- `GET /teacher/api/knowledge/chunks?knowledge=...&chapter=...&offset=0&limit=20`：分页查看原文内容块。
- `GET /teacher/api/knowledge/import-status?key=...`：读取、分块、素材等处理阶段。
- `POST /teacher/api/knowledge/unit`：建立范围引用，沿用工作台来源及令牌校验。

目录提取、章节索引、分块和本次迁移的模型调用均为 0。生成教学材料、视觉方案和 AI 图片描述仍使用原有模型流程。
