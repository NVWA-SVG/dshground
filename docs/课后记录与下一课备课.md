# 课后记录 → 班级学情 → 下一课备课

已将默认课后流程调整为记录教学成果与课堂表现，为后续同班教学提供依据。课后不要求重新生成已经上完的课程。

## 教师使用

1. 上完课，打开原课程的「课后记录」。只需填写「本节课表现」，可选填写「下次教学关注」。实际用时、参与人数、检测情况和有效做法有记录再补充。
2. 点击「保存课堂记录」。系统在本机归档，分别整理课堂参与、学习表现、节奏与时间、教学做法与偏好，并保留原话、授课日期与来源。保存不调用模型，不创建旧课修订任务，不增加材料版本。
3. 点击「为本班备下一课」。系统自动沿用班级；教师填写新课主题和要求，正常生成一套新课材料。其他入口新建备课时也可选择已有班级，读取其相关学情。

「班级学情」展示这些待持续核对的线索；班级基础信息和原始记录折叠查看。一次活跃表现不当成掌握，估计值不当成实测值，教师偏好不当成已验证的有效性结论。不自动生成固定学生能力标签或虚构分组人数。

## 上下文与记录

- 新课依据当前目标、教师要求和相关先备知识选用历史记录，在现有上下文预算内提供证据及对应课堂线索。来源被预算剔除时，对应线索也不进入模型上下文。
- 新课提示词要求将相关学情落实到支架、举例、独立练习、交流方式、节奏或检测，并在设计说明里引用反馈 ID。旧课调整意愿不自动成为新课必须执行的指令。
- 已记录的环节实际用时及其信息密度单独携带观察/估计口径，不自动生成课堂质量分或因果结论。
- 更正记录会保留原记录供追溯；后续备课仅使用最新记录，避免更正前后重复当成多份证据。日期、同题多次检测和不同记录依据继续保留。
- 历史课程、课件、反馈和旧修订版本保留。旧版 API 的修订能力保持兼容；新 UI 的课后记录明确标记为后续教学用途，后端也拒绝将它直接变成旧课修订。
