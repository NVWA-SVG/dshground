# Agent 页面规划与混合配图

日期：2026-11-09。教师入口仍为「创建课程并生成整套材料」。

## 当前行为

Qwen 先生成教学设计，再逐页规划布局、选择教材原图并按需提出生图要求。宿主通过 SiliconFlow 的 Qwen-Image 生成插画，保存到本地后，与教材原图、原生文字和图形一起由 python-pptx 装配。整套交付仍只有一份最终 PPT。

教材原图不改绘、不裁掉内容；留空题继续按原题截图插入页面底部。标题、正文和讲稿保持原生文本。生成插画标注「AI 生成插画」，保留供应商默认水印。课后记录仍用于后续同班备课。

页面方案新增 `layout_kind`（左右图文、上图下文、对比、分步、文字）、`image_prompt`、`image_reason` 与全局 `palette`。`asset_ids` 仍选择教材原图，两种来源可以同时出现在一页。生图仅在明确填写 image_prompt 且启用服务时进行。精确题干、公式、钟面读数等优先保留教材原图或可编辑图形。

本地模式即使没有教材图片也会生成页面方案，允许使用 AI 插画或纯原生内容。生图失败不会把基础文字稿显示为完成。

## 配置与接口

「课件外观与服务」新增「AI 插画与教材原图搭配」：可开关生图，设置每课张数上限，以及模型、尺寸、步数、代理和兼容 API。SiliconFlow 沿用本机 SILICONFLOW_API_KEY；兼容服务单独使用 IMAGE_API_KEY。

- `GET /teacher/api/image/settings`：返回配置和 configured，不返回密钥。
- `POST /teacher/api/image/settings`：保存配置，密钥仍进入本机凭据库。
- `POST /teacher/api/image/test-connection`：读取模型列表核对所选模型，不创建生图任务。
- 配置文件：`config/image-generation.json`，示例：`config/image-generation.example.json`。
- 本机初始配置：SiliconFlow，Qwen/Qwen-Image，1472x1140，50步，每课最多4张，按需生成。

API 协议依据 [SiliconFlow 图片生成文档](https://docs.siliconflow.cn/docs/api/images-generations-post)。使用 `/v1/images/generations`，保留默认水印，不发送已下线的 batch_size。实际可用模型以当前账号和服务设置为准。

图片、逐页索引和恢复记录保存在 `data/ppt-runs/<run>/generated/`。下载成功后不保留临时下载 URL；下载失败时保留已有回执，再次继续只下载同一结果。POST 回执不明确时暂停，继续不会自动再次创建；主动重新制作会新建任务，可能再次计费。每课生图数在发出请求前检查。
