# Windows 教师工作台使用说明

## 打开工作台

双击桌面「教师工作台」，或 `C:\DSH\打开教师工作台.vbs`，等待本地服务启动。访问地址为 `http://127.0.0.1:3081/teacher/`。无需 Ubuntu 或手动选择技能。

2026-11-17 已清空旧业务数据，模型配置与密钥保留。首次重新使用时，知识库和课程列表为空。

## 从输入到材料输出

1. **设置模型。** 打开「模型设置」，确认文本模型与连接参数。「课件外观与服务」管理本地课件、教材配图及可选生图模型；视觉模型设置用于教材图片描述。密钥保存在本机，不在界面回显。
2. **导入教材。** 点击「知识库」，上传 PDF、DOCX、TXT 或 MD。上传大小和 PDF 页数上限以面板显示为准；本课临时资料仍有独立的大小限制。系统在本机保存原件、抽取文字、梳理目录、按章节分块，并截取教材插图与留空题区域。整册与章节通过页码引用共用内容和图片。
3. **检查知识库。** 查看章节、内容块和教材素材，必要时补充名称、学科、年级或教学范围。「AI 描述」会调用已配置的视觉模型；可选择识别范围、查看进度或暂停，已有描述与缓存会复用。扫描件若缺少可提取文字，需要提供 OCR 文字。
4. **创建备课。** 点击「新建备课」，填写主题、课程类型、年级、学科、课时与班级。人数、已学内容和困难可以按实际情况选填。勾选本课教材；同一班级再次备课时选择已有班级，以参考过去的课堂记录。
5. **生成整套材料。** 点击「创建课程并生成整套材料」。系统先检索本课相关教材和学情，再生成教学设计与逐页视觉方案，按需选择原图、生成补充插画，并在本地装配课件、导出文档和校验打包。无需手动传递制作提示词。
6. **核对与下载。** 在教学材料页下载一份最终可编辑 PPTX、教案、逐字稿、检测题或整套 ZIP。文字与常规图形可编辑，教材截图及生成插画仍是图片。「信息密度」展示首次引入知识点、环节时间与思考练习安排。正式使用前打开 Office 核对版式、知识和适龄性。
7. **记录课堂成果。** 授课后在「课后记录」填写实际观察、学生困难、参与或检测证据，按需补充明细。记录用于积累班级特点，供下一课因材施教，不自动重做已经讲完的课程。未知留空，记录为零时填 0。

## 中断与继续

刷新或关闭教师窗口不会停止后台任务。重新打开后可查看进度；整套材料未完成时，按页面提示「继续生成整套材料」。不要反复创建同一课程。

电脑重启或服务退出后，未完成任务可能需要手动继续。模型错误的原因可在任务详情及本机日志中查看。连接检查通过不代表账号有足够的生成额度。

## 信息密度与学情

计划密度为环节首次引入知识点数除以计划分钟；实际密度依据教师记录的实际时间。没有填写时保持未知。练习、讨论即使没有新增知识点，仍有教学价值。

密度、参与、检测和教师观察分别呈现。课堂活跃不能直接等同于掌握程度；后续备课应结合具体学习证据。旧版本属于课程的历史设计记录，不是教材的重复副本；本次清理已全部移除旧记录。

## 文件与维护

| 位置 | 用途 |
| --- | --- |
| `C:\DSH\backend`、`plugins` | 当前后端与教师插件源码 |
| `C:\DSH\config` | 模型、上下文、教材导入与配图配置 |
| `C:\DSH\runtime`、`harness-home\profiles` | Windows DSH 运行依赖与加载配置 |
| `C:\DSH\harness-home\.credentials.yaml` | 本机模型凭据 |
| `C:\DSH\data` | 数据库、教材素材、任务及运行日志 |
| `C:\DSH\inputs` | 待导入的资料 |
| `C:\DSH\deliverables` | 新生成的材料与保留的源码部署包 |

运行 `停止教师工作台.cmd` 才会停止后台服务；关闭窗口只关闭界面。运行 `python C:\DSH\tools\run_cli.py doctor` 可检查本地 Python 依赖和数据库。

接入协议见 [PPT API 接口](PPT_API接入说明.md)、[混合配图](混合配图课件接入与验收.md)、[生成调参](备课助手上下文与调参接口.md) 和 [课后记录](课后记录与下一课备课.md)。
