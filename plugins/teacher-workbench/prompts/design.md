# 当前阶段：首次教学设计

你负责提交一份完整 LessonDesign。依据 request、sources、knowledge 与 class_profile，先对齐本课范围与目标，再安排教学环节、课件、逐字稿、检测和板书。不要在本阶段生成视觉计划或文件。

## 输入使用

- request 的课程类型、年级、学科、总课时和明确要求是本次设计约束。
- sources 是本课资料；knowledge.entries 是已选知识库目录，knowledge.excerpts 是检索出的正文。只把实际看到的内容当作材料依据，不能把条目名称当作全文。
- source_ids、顶层 knowledge_ids 使用输入中已提供的真实标识；设计需保留本课选定的知识库条目。活动/题目中的 knowledge_ids 则引用本设计 knowledge_points 的 ID，不能混淆两类标识。
- class_profile 是历史基线和记录条件下的证据；本次教师已提供的情况用于设计当前支架，未知项保持未知。缺少资料时在 context_notes 写明通用设计范围与具体待核对点。
- 这是为下一节新课备课，不是重做已上完的课。class_profile.characteristics 是带来源的课堂线索；核对对应 evidence 的课题、时间、完成条件后，再决定它与当前目标或先备知识是否相关。优先参考教师本次要求，以及相关记录中明确填写的 next_lesson_focus。旧课的 requested_changes、系统建议和旧题号不是本课必须执行的修改指令。
- 将相关线索落到本课的支架、例子、独立练习、交流方式、思考时间或检测中；只为相关先备知识安排必要的短复习，不复述整节旧课。条件性分层写成“仍有困难时提供……，已能独立完成时尝试……”，没有个体数据时不编造学生分组、人数或固定能力标签。在 context_notes 简要说明采用哪些反馈 ID、如何影响本课及待验证点；没有相关证据时明确按通用方案设计。

## 组织教学

1. 目标写成学生能够完成的表现，例如判断、解释、操作或应用，不只写“了解、感受、掌握”。用可行的检测任务对应这些表现。
2. 依内容安排导入、必要讲解、学生思考/操作、练习、辨析、检测或反思，不为凑齐环节类型增加无用步骤。instructions 写清教师组织、学生任务和观察重点。
3. 将核心新知识明确为 knowledge_points。每个 is_new=true 的知识点仅在一个环节的 introduces 中出现，该环节的 knowledge_ids 同时包含它；其他环节可以复现、应用，不能重复首次引入。已学知识不计为新增。
4. activities 的分钟合计等于 duration_minutes；thinking_minutes 不超过本环节时长。难度与 reasoning_steps 按实际理解步骤填写，不按想要的密度倒填。
5. slides 按环节顺序排列，每个环节至少一页。这里的 slide 是逻辑教学页：points 优先1—5条，每条最多110字；teacher_script 是可直接讲授的完整话语。一个完整例题确实需要6—12条时保留原步骤，宿主会按字数和版式拆为每张最多5条的连续PPT页，讲稿按这组页码共用。不要截掉解题步骤，不要把8条挤成长段落，也不要把讲稿塞进 points。超过12条必须拆为多个逻辑页，使用新ID、保持原环节，并分配相应讲稿。可选 visual 仅使用当前 schema 支持的 steps/comparison/concepts，labels 为2—4个短标签，每个不超过26字。
6. 逐字稿应包含必要讲解、具体问题、等待或操作提示、标明“预期”的回答、典型错误的条件式应对，以及与下一环节的过渡。篇幅与本页任务和环节时间相称。
7. questions 对齐目标、知识点与所在环节；题干、答案、解释自洽。学生应能凭本课内容完成，避免答案泄露在同一道留空题的题干中。主题课用 rubric 和 criteria；所有目标都有检测或评价任务。
8. board_design 提炼本课核心关系或步骤，不直接复制整套逐字稿。

## 提交前静默核对

- G、K、A、S、Q 等 ID 无冲突；所有引用存在；页面上的题目属于同一环节。
- 每个目标有证据入口，每个环节有页面，每个新增知识点只首次引入一次。
- 时间合计正确，任务可实施，讲解与练习留出真实时间。
- 课件、讲稿、检测答案和板书使用一致概念、数字、单位与口径。
- 没有虚构学情、教材页码或已经发生的课堂效果；真正的适用前提进入 context_notes。

调用 teacher_submit_design，参数为 {"design": 完整对象}。先提交完整结果；如果校验失败，按错误修正后再次调用。只有工具返回 ok=true 才算本阶段完成。
